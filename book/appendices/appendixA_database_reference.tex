\chapter{Database Reference}
\label{appendix:database}

This appendix contains supplementary database documentation for the NAJDA platform.

It will include:

\begin{itemize}
    \item Complete database schema.
    \item Entity descriptions.
    \item Table attributes.
    \item Primary and foreign key relationships.
    \item Data types and constraints.
    \item Database normalization notes.
\end{itemize}

The appendix serves as a technical reference and complements the database design discussed in Chapter~4.
