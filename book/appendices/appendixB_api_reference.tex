\chapter{REST API Reference}
\label{appendix:api}

This appendix provides the REST API reference for the NAJDA backend services.

The final version will include:

\begin{itemize}
    \item Authentication endpoints.
    \item Incident management endpoints.
    \item Dispatch endpoints.
    \item Hospital management endpoints.
    \item Administrative endpoints.
    \item Example request and response payloads.
    \item HTTP status codes.
\end{itemize}

Detailed endpoint implementation is discussed throughout Chapter~5.
