\chapter{Additional User Interface Screens}
\label{appendix:ui}

This appendix contains supplementary user interface designs that are not included within the main chapters.

Examples include:

\begin{itemize}
    \item Citizen mobile application screens.
    \item Dispatcher dashboard screens.
    \item Ambulance crew interface.
    \item Firefighter interface.
    \item Police interface.
    \item Hospital staff interface.
    \item Administrator dashboard.
\end{itemize}

Only representative interfaces are discussed in the implementation chapter, while the remaining designs are provided here for completeness.
