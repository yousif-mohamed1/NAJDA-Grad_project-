\chapter{Design Decisions and Assumptions}
\label{appendix:decisions}

This appendix summarizes the major architectural decisions made during the design of RapidAid together with the assumptions adopted throughout the project.

Topics documented include:

\begin{itemize}
    \item Event-driven microservice architecture.
    \item Spring Boot backend services.
    \item FastAPI AI service.
    \item RabbitMQ event broker.
    \item PostgreSQL as the system of record.
    \item Redis for live GPS caching.
    \item Firebase Authentication, Cloud Messaging, and Storage.
    \item ShiftAssignment-based dispatch model.
    \item AI-assisted decision support philosophy.
    \item Simulation scope and project limitations.
\end{itemize}

The rationale for each decision is discussed in Chapter~4, while this appendix serves as a consolidated reference for future maintenance and project extension.
